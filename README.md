## 🚀 How to Run the Script in this Repository
You don't need a full Linux OS to run the script in this repository. You can use **Git Bash** on Windows or any online Linux terminal.

1. Open your terminal (**Git Bash** or Linux Terminal) in the folder containing `script.sh`.
2. Give the script execution permissions (optional but recommended):
   ```bash
   chmod +x script.sh
   ```
3. Run the script:
   ```bash
   ./script.sh
   ```
   *(Alternative: If you haven't changed permissions, you can just type `bash script.sh`)*

## 🛠️ Useful Linux Commands (My Practice Cheat Sheet)
Here are the essential commands I am practicing to navigate and control the Linux terminal:

### 📁 File & Directory Navigation
* `pwd` — **Print Working Directory.** Shows exactly which folder you are currently inside.
* `ls` — **List.** Lists all the files and folders in your current directory.
* `cd <folder_name>` — **Change Directory.** Moves you into a different folder (e.g., `cd Desktop`).
* `cd ..` — **Go Back.** Moves you up one level to the parent folder.

### 📄 Creating & Managing Files
* `mkdir <name>` — **Make Directory.** Creates a brand new folder.
* `touch <filename>` — **Touch.** Creates an empty file (e.g., `touch notes.txt`).
* `cat <filename>` — **Concatenate.** Displays the text contents of a file right inside the terminal.
* `rm <filename>` — **Remove.** Permanently deletes a file.

### ⚙️ System Shortcuts
* `clear` — Cleans up the terminal screen if it gets too cluttered.
* `history` — Shows a list of all the commands you have typed recently.

## 💡 5 Fun & Mind-Blowing Linux Facts
As I practice Linux, I discovered some incredible facts about it:

1. **Powered by a Penguin:** The official mascot of Linux is a penguin named **Tux**. The creator of Linux, Linus Torvalds, chose a penguin because he was famously nipped by one at a zoo!
2. **Runs the Entire Internet:** Over **96.3% of the world's top 1 million web servers** run on Linux. The internet as we know it completely relies on it.
3. **Dominates Space & Science:** Linux runs **100% of the world's top 500 fastest supercomputers**, controls the International Space Station (ISS), and powers NASA’s Mars Rovers.
4. **It’s Inside Your Pocket:** If you own an Android smartphone, you are using Linux! The **Android operating system** is built directly on top of the Linux kernel.
5. **Completely Community Driven:** Linux is open-source. This means thousands of developers worldwide collaborate to update it daily for free, making it incredibly secure and fast.
